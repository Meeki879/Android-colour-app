# Family Test Kit (Phase 1 validation)

Purpose: test whether the problem is real and whether the app solves it, before building Phase 2.
The same group can also serve as the Google Play closed test that new personal developer accounts must run before public release (check the current tester count and duration in Play Console).

## Who

- Your own family (ages 5 and 1)
- 5 families, at least 2 with a neurodivergent child aged 2 to 8
- 1 occupational therapist or SEN teacher reviewing the app

## Setup (day 0)

1. Install through the Play Console internal or closed test track.
2. Parent turns on App pinning, guided by the Grown-ups help screen.
3. Parent sets the play timer to 15 minutes.
4. Parent reads the safety notice.

## Observed first session (day 1, about 10 minutes)

Record yes/no or a short note for each:

| Check | Note |
|---|---|
| Child touches the screen without being shown how | |
| First reaction: smiles, vocalises, ignores, withdraws | |
| Signs of overstimulation: covering eyes or ears, distress, sustained slapping over 30 s | |
| Child leaves the app by accident | |
| Child triggers the corner exit by accident | |
| Parent finds the Grown-ups area without help | |
| If overstimulated: does low-stimulation mode help? | |

## Days 2 to 13

No prompting. The parent offers the app only as they would any other toy and notes anything unusual.

## Day 14

1. Parent opens Grown-ups > Play summary > Copy summary and pastes it into the feedback message.
2. Parent answers:
   - How would you feel if this app disappeared tomorrow? (very disappointed / somewhat disappointed / not disappointed)
   - When did your child use it most (wind-down, waiting, travel, other)?
   - What did you use before for the same moments?
   - What one change would make it better?
   - Would you recommend it to another parent? Who?

## Proposed pass thresholds

These are proposals, to confirm before testing starts.

- At least 3 of 5 families: the child played on 5 or more of the 14 days without being prompted (Play summary: days played).
- No overstimulation incident that low-stimulation mode did not resolve.
- At least 2 parents answer "very disappointed".

If the thresholds are met, build Phase 2 (obstacles and wave simulation). If not, fix what the notes point to before adding features.
